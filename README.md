# 💼 JobTrackr

A modern ASP.NET Core MVC web application that helps job seekers organize and monitor their job applications from one central dashboard.

JobTrackr enables users to keep track of applications, interview invitations, offers, and rejections while storing important information such as company details, application dates, and application status.

---

# 📖 Overview

Searching for a job can involve submitting dozens of applications across multiple companies. Keeping track of every application manually can become difficult.

JobTrackr was developed to simplify this process by providing a centralized platform where users can manage their job search efficiently.

The application demonstrates full-stack web development using ASP.NET Core MVC, Entity Framework Core, and SQL while implementing software engineering best practices.
